# Flashcards

An Android app for studying with flashcards, designed so that missing a day costs nothing.
Cards are written by hand or generated by AI from a block of text or a web page.

## Language

### Content

**Deck**:
A named collection of Cards on one topic. The unit a Session is drawn from.
_Avoid_: Set, collection, category, topic

**Card**:
One idea, with a Front and a Back. Never two ideas.
_Avoid_: Note, item, question

**Front**:
The prompt side of a Card — a short term or a direct question.
_Avoid_: Question, term, prompt

**Back**:
The answer side of a Card — one plain sentence.
_Avoid_: Answer, definition, meaning

### Generation

**Source**:
The raw material a Deck is generated from: either pasted text or a URL.
_Avoid_: Input, material, content

**Generation**:
One AI request that turns a Source into a Deck name and a list of Cards.
_Avoid_: Import, extraction, parsing

**Kept**:
A generated Card the user ticked to include before saving. Unkept Cards are discarded, never stored.
_Avoid_: Selected, accepted, approved

### Studying

**Session**:
One sitting of a fixed, small number of Cards drawn from a single Deck. Ends where the user can see the end from the start.
_Avoid_: Study, run, round, practice

**Session length**:
How many Cards a Session contains — a user setting, one of 3, 5, or 10.
_Avoid_: Size, count, limit

**Review**:
The phase of a Session where Cards are shown one at a time and graded.
_Avoid_: Study, drill, practice

**Grade**:
The user's verdict on a Card during Review: `Knew it` or `Again`.
_Avoid_: Rating, score, answer, result

**Mastery streak**:
The number of consecutive `Knew it` grades on a Card. `Again` resets it to zero.
_Avoid_: Score, level, box, strength

**Mastered**:
A Card whose Mastery streak has reached the mastery threshold. Rarely resurfaces in Sessions.
_Avoid_: Known, learned, done, retired

**Learning**:
Any Card that is not Mastered. The default state of a new Card.
_Avoid_: New, unlearned, in progress, weak

**Miss**:
A Card graded `Again` during a Session. Listed on the results screen as worth another look.
_Avoid_: Failure, wrong answer, lapse

### Progress

**Session log**:
One row per Session, written when the sitting ends. Every figure on the Progress screen is
counted from it, and nothing else counts anything.
_Avoid_: History, stats, activity

**Day streak**:
The number of consecutive days with at least one Session. A gap ends it, but the copy always
says the streak is held rather than lost, and the user can hide it entirely.
_Avoid_: Streak on its own — that is the Mastery streak. Also: chain, run
